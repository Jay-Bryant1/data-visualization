# 统计局代码 · 固定资产投资和房地产

生成 `年度数据/固定资产投资和房地产/` 下全部图表的脚本。共 **47 个源文件 → 46 张逐表图 + 1 张驾驶舱**
（`45` 与 `44` 数值完全相同，作为重复件跳过）。

> 取数一律走官网手工导出（年度数据 → 固定资产投资和房地产 → 选表 → 右上角「下载」），本项目**不含任何爬虫**。

## 目录

```
统计局代码/
├── stj_core.py                 母版：解析 + 指标计算
├── charts.py                   母版：图版
├── render.py                   母版：批量流程
├── sync_core.py                母版分发：--check / --push / --pull
└── 固定资产投资和房地产/        ← 本目录（自包含，可整目录拷走）
    ├── stj_core.py             核心副本（勿手改，由 sync_core.py 覆盖）
    ├── charts.py               核心副本
    ├── render.py               核心副本
    ├── build_all.py            分类入口
    ├── dashboard.py            数据驾驶舱（一页式看板）
    └── README.md

年度数据/固定资产投资和房地产/  ← 47 个 CSV + 46 张逐表图 + 1 张驾驶舱
```

三个核心模块在本目录各存一份，`sys.path` 只指向本目录，把本目录与
`年度数据/固定资产投资和房地产/` 一起拷走即可独立运行。改代码改母版，再用
`python 统计局代码/sync_core.py --push` 分发。

运行：

```bash
python 统计局代码/固定资产投资和房地产/build_all.py          # 出图
python 统计局代码/固定资产投资和房地产/build_all.py --check   # 只体检
python 统计局代码/固定资产投资和房地产/dashboard.py          # 驾驶舱
```

## 文件命名规则

官网导出名一律是 `年度数据 (n).csv`，`n` 只反映下载顺序。本目录按**官方表序 + 内容**重命名，
`01-` 这类序号前缀只在文件系统里有意义，**图标题会自动剥掉它**（`render._ORDER_PREFIX`）。

## 已知的数据坑（代码里已处理）

- **百级指标不能铺小倍数**。`09`–`29` 每张表有 98–113 个行业，铺成面积矩阵要 29 行、
  画布高 55 英寸，单格不足 2 英寸宽，趋势根本看不出来。改为**矩阵热力图**：行按最新一年
  增速排序，颜色就是增速（暖＋冷−），行数超过 46 自动分栏并排。
- **率类指标的变化率不能按相对数算**。全社会固定资产投资增速从 6.9% 掉到 −3.9%，
  按相对变化算是 −156.5%，这个数字既无含义也无从核对；改为**百分点差**（−10.8pp）。
  起点为零或负的量级指标同样回落到差值，不再出现 −394.6% 那种数。
- **2025 年是 2016 年以来唯一的负增长**。全社会固定资产投资增速序列为 6.9 / 6.1 / 5.9 / 5.1 /
  2.6 / 4.8 / 4.8 / 2.8 / 3.1 / −3.9，2020 年是 **+2.6%** 而非负值，所以速读条写「为 2016 年
  有记录以来首次转负」，不能写成「2020 年以来首次转负」——年份一对就露馅。这句由
  `_first_negative_note()` 从数据数出来，不手写。
- **两套房地产口径不能拼成一条线**。`31`/`33`（2013–2022）与 `32`/`34`（2023–2024）
  是《关于市场主体统计分类的划分规定》（国统字〔2023〕14 号）前后的两段，指标名几乎一样
  （「港、澳、台投资」vs「港澳台投资」），数值却不可直接相连；文件名里标了年份区间，
  逐表出图，不做跨段拼接。
- **`45` 是重复件**。与 `44-房地产开发企业主营业务收入` 数值逐格相同（文件字节不同），
  已跳过，不重复出图。
- **单位藏在括号里且写法多样**。「万平方米」「套」「元/平方米」过去认不出，图标题会丢掉单位；
  解析器已改为「量纲词结尾 + 足够短 + 不含口径词」三条判定，`38` 这类一张表混五种单位的
  也能逐格标对。
- **2025 年房地产开发投资相关指标多数未发布**。`05`（房地产投资增速）、`42`（均价）、
  `43`–`47` 的最后一年是 2024；副标题按成因分开写（「2025 年未发布」与「该口径只统计到
  较早年份」），不把停发写成漏采。
- **`47` 的套数无单位标注**。原表只写「住宅竣工套数」，单位「套」在图标题里补出。
