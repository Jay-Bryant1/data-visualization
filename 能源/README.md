# 统计局代码 · 能源

生成 `年度数据/能源/` 下全部图表的脚本。共 **37 个源文件 → 37 张逐表图 + 1 张驾驶舱**。

> 取数一律走官网手工导出（年度数据 → 能源 → 选表 → 右上角「下载」），本项目**不含任何爬虫**。

## 目录

```
统计局代码/
├── stj_core.py                 母版：解析 + 指标计算
├── charts.py                   母版：图版
├── render.py                   母版：批量流程
├── sync_core.py                母版分发：--check / --push / --pull
└── 能源/                        ← 本目录（自包含，可整目录拷走）
    ├── stj_core.py             核心副本（勿手改，由 sync_core.py 覆盖）
    ├── charts.py               核心副本
    ├── render.py               核心副本
    ├── build_all.py            分类入口
    ├── dashboard.py            数据驾驶舱（一页式看板）
    └── README.md

年度数据/能源/                   ← 37 个 CSV + 37 张逐表图 + 1 张驾驶舱
```

三个核心模块在本目录各存一份，`sys.path` 只指向本目录，把本目录与
`年度数据/能源/` 一起拷走即可独立运行。改代码改母版，再用
`python 统计局代码/sync_core.py --push` 分发。

运行：

```bash
python 统计局代码/能源/build_all.py          # 出图
python 统计局代码/能源/build_all.py --check   # 只体检
python 统计局代码/能源/dashboard.py          # 驾驶舱
```

## 数据驾驶舱

`dashboard.py` → `年度数据/能源/能源数据驾驶舱.png`（16×9.6 in @200dpi）。

| 区块 | 内容 |
|---|---|
| 标题区 | 图标 + 「能源 · 数据驾驶舱」+ 数据区间，右侧年份与「标煤口径」胶囊 |
| 年份滑轨 | 2016–2025 十个刻度，已走过段描深，当前年份落点 |
| KPI 条 | 能源消费总量 / 一次能源生产总量 / 原煤产量 / 发电量 / 煤炭消费占比 |
| 速读条 | 一段「2025 速读」，数字全部由表实时算出，不写死 |
| 主副图 | 左：消费 / 生产两层面积（亿吨标准煤），中间沙色带即供需缺口；右：消费品种结构 100% 堆叠 |
| 底部三联 | 主要能源产品产量（四格迷你面积，实物量）、2023 年能源消费前 8 个行业、一次能源生产结构 |

驾驶舱只吃 `11`（生产构成）、`14`（消费总量及构成）、`15`（分行业消费）、`37`（产量）四张表。
**分行业明细发布到 2023 年**，行业排名自动取 2023 年；「第几年」全部由数据算出，不写死。

## 文件命名规则

官网导出名一律是 `年度数据 (n).csv`，`n` 只反映下载顺序。本目录按**官方表序 + 内容**重命名
（`01`–`37`），保证在资源管理器里按表序排列。图标题会自动剥掉序号前缀（`render._ORDER_PREFIX`）。

## 已知的数据坑（代码里已处理）

- **分行业分品种明细只发到 2023 年**。`16`–`24` 九张表 2024 年起停更，空白为口径停止发布，
  页脚已逐表注明；不要把它读成漏采，也不要拿 2023 年的行业结构去描述 2025 年。
- **`15` 分行业能源消费的末两年是「半张表」**。2025 年只发布能源消费总量一行；2024 年只更新
  农林牧渔、工业、建筑业、交通运输、居民生活等门类，采矿业与制造业的细分行业停在 2023 年。
  热力图副标题同时写了「2025 年部分指标未发布」与「另有 N 个指标只统计到较早年份」。
- **`09`/`10` 能源工业固定资产投资只有 2016–2017 两年**。2018 年起该分组不再单列发布，
  图上是两年的散点而不是趋势线，标题旁的散点矩阵只连真实观测点。
- **`05` 一张表里有两组不同末年的指标**：人均原煤、人均原油、人均电力**生产量**更新到 2024 年，
  人均能源**生产总量**与人均能源、煤炭、石油、电力**消费量**停在 2022 年。右端空白不是整表停发。
- **`14` 的总量与构成更新到 2025 年，分品种消费量停在 2023 年**。总量与四个占比可以连到
  2025 年，煤炭、焦炭、原油、汽油、煤油、柴油、燃料油、天然气、电力的实物量只到 2023 年。
- **`37` 汽油、柴油产量停在 2024 年**，原煤、原油、天然气、焦炭、发电量更新到 2025 年。
- **`01` 弹性系数无量纲**（能源／电力生产量或消费量增速 ÷ GDP 增速），单位写作 `(-)`，
  解析后按「单位未标注」处理；能源生产弹性系数缺 2016 年（未发布）。
- **平衡表里的负值是口径本身**：「出口量 (-)」「年初年末库存差额」「平衡差额」可为负，
  图上纵轴下探并画零线，面积从 0 基线向负方向填充，不会把负值裁掉。
- **恒为 0 的科目会被剔除**。原油、燃料油等品种在多数行业并不消费，原表给的是 0，画出来是
  一条压在地面的直线；`29`–`34` 会剔掉这类行，副标题写明「已略去 N 个恒定科目」。
- **能源品种单位有三种写法**：热量为「万吨标准煤」，电量为「亿千瓦小时」（不是「千瓦时」），
  供热能力为「兆瓦」、蒸汽为「吨/小时」，生活热力为「万百万千焦」。这些单位已补进
  `stj_core` 的单位识别表，否则图上会显示「单位未标注」。
- **`03` 平均每天能源消费量的合计与分品种不可相加**：合计按万吨标准煤折算，分品种保留各自的
  实物量单位（万吨、亿立方米、亿千瓦小时）。
- **驾驶舱的「缺口＝消费−生产」不等于净进口**：它还含年初年末库存差额与统计误差，
  脚注已写明，避免把差额直接当对外依存度使用。
