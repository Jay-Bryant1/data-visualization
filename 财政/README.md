# 统计局代码 · 财政

生成 `年度数据/财政/` 下全部图表的脚本。共 **15 个源文件 → 15 张逐表图 + 1 张驾驶舱**。

> 取数一律走官网手工导出（年度数据 → 财政 → 选表 → 右上角「下载」），本项目**不含任何爬虫**。

## 目录

```
统计局代码/
├── stj_core.py                 母版：解析 + 指标计算
├── charts.py                   母版：图版
├── render.py                   母版：批量流程
├── sync_core.py                母版分发：--check / --push / --pull
└── 财政/                        ← 本目录（自包含，可整目录拷走）
    ├── stj_core.py             核心副本（勿手改，由 sync_core.py 覆盖）
    ├── charts.py               核心副本
    ├── render.py               核心副本
    ├── build_all.py            分类入口
    ├── dashboard.py            数据驾驶舱（一页式看板）
    └── README.md

年度数据/财政/                   ← 15 个 CSV + 15 张逐表图 + 1 张驾驶舱
```

三个核心模块在本目录各存一份，`sys.path` 只指向本目录，把本目录与
`年度数据/财政/` 一起拷走即可独立运行。改代码改母版，再用
`python 统计局代码/sync_core.py --push` 分发。

运行：

```bash
python 统计局代码/财政/build_all.py          # 出图
python 统计局代码/财政/build_all.py --check   # 只体检
python 统计局代码/财政/dashboard.py          # 驾驶舱
```

## 数据驾驶舱

`dashboard.py` → `年度数据/财政/财政数据驾驶舱.png`（16×9.6 in @200dpi）。

| 区块 | 内容 |
|---|---|
| 标题区 | 图标 + 「财政 · 数据驾驶舱」+ 数据区间，右侧年份与「决算」胶囊 |
| 年份滑轨 | 2016–2025 十个刻度，已走过段描深，当前年份落点 |
| KPI 条 | 一般公共预算收入 / 支出 / 收支差额 / 税收收入 / 中央财政债务余额 |
| 速读条 | 一段「2025 速读」，数字全部由表实时算出，不写死 |
| 主副图 | 左：支出 / 收入两层面积（亿元→万亿元）+ 缺口圆点（右轴，负值）；右：支出功能结构 100% 堆叠 |
| 底部三联 | 四大税种占税收比重（100% 堆叠，含「其他税种」）、2024 年支出功能前 8 项、收入的中央与地方分成 |

驾驶舱只吃 `01`（收支总额）、`02`（分级收入）、`07`（支出功能）、`10`（各项税收）、
`11`（中央债务）五张十年连续的表。**2025 年支出功能明细缺 4 项**，结构与排名自动回退到
2024 年；「第几年」全部由数据算出，不写死。

## 文件命名规则

官网导出名一律是 `年度数据 (n).csv`，`n` 只反映下载顺序。本目录按**官方表序 + 内容**重命名
（`01`–`15`），保证在资源管理器里按表序排列。图标题会自动剥掉序号前缀（`render._ORDER_PREFIX`）。

## 已知的数据坑（代码里已处理）

- **营业税 2016 年 5 月起停征**。`04`/`05`/`06`/`10` 里的「营业税」只有 2016 年一个观测点，
  图上会显示一枚孤点并注明「仅 1 个年度有数」——那是营改增全面推开，不是漏采。
- **进口环节增值税、消费税自 2017 年起并入国内增值税列示**，`04`/`05` 里这两行同样只有
  2016 年一个点。跨 2016 年的增值税增减不可直接比较，页脚已注明。
- **预算外资金是另一套口径、另一段时间**。`12`–`14` 只覆盖 2001–2010 年（2011 年起预算外
  资金全部纳入预算管理、不再单独统计），与 2016 年起的其它表完全不重叠，**不可拼接**。
- **2025 年只发布了收支总量与主要税种**，`04`、`05` 的税种明细、`07` 的 4 项功能支出
  （外交、公共安全、文化体育与传媒、其他）仍为空白。副标题按成因分开措辞：
  「2025 年部分指标未发布」与「另有 N 个指标只统计到较早年份」是两回事。
- **`06` 地方财政决算明细只到 2024 年**，2025 年未发布，因此该表年份比同级的 `05` 少一年。
- **`14` 预算外支出分功能只有 2007–2010 四年有数**，此前年份按旧科目发布，未并入本表；
  图上按真实年份落点，不做插补。
- **`15` 是混合量纲**：余额为亿美元，偿债率 / 负债率 / 债务率为 %。图上按单位分格，
  率类指标的首末变化写百分点差（+0.4pp），不写成百分比变化（那会把 6.1%→6.5% 说成 +6.6%）。
- **支出功能结构里的「其余各项」是轧差项**：由当年一般公共预算支出总额减去教育、社保就业、
  农林水、城乡社区、一般公共服务、医疗卫生六项得到，含国防、科技、交通、环保、债务付息等，
  以及本表未单列的支出。驾驶舱脚注已写明，不把它当作独立统计口径引用。
- **驾驶舱的收支缺口＝支出−收入**（负值为赤字），与「财政赤字」概念接近但不完全等同：
  后者还要扣除调入资金与结转结余。图上只作收支轧差呈现。
