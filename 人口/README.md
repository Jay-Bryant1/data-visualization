# 统计局代码 · 人口

生成 `年度数据/人口/` 下全部图表的脚本。共 **16 个源文件 → 15 张逐表图 + 1 张驾驶舱**
（1 个完全重复的导出被 sha256 识别后跳过）。

> 取数一律走官网手工导出（年度数据 → 人口 → 选表 → 右上角「下载」），本项目**不含任何爬虫**。

## 目录

```
统计局代码/
├── stj_core.py                 母版：解析 + 指标计算
├── charts.py                   母版：图版
├── render.py                   母版：批量流程
├── sync_core.py                母版分发：--check / --push / --pull
└── 人口/                       ← 本目录（自包含，可整目录拷走）
    ├── stj_core.py             核心副本（勿手改，由 sync_core.py 覆盖）
    ├── charts.py               核心副本
    ├── render.py               核心副本
    ├── build_all.py            分类入口
    ├── dashboard.py            数据驾驶舱（一页式看板）
    └── README.md

年度数据/人口/                  ← 16 个 CSV + 15 张逐表图 + 1 张驾驶舱
```

三个核心模块在本目录各存一份，`sys.path` 只指向本目录，把本目录与
`年度数据/人口/` 一起拷走即可独立运行。改代码改母版，再用
`python 统计局代码/sync_core.py --push` 分发。

运行：

```bash
python 统计局代码/人口/build_all.py          # 出图
python 统计局代码/人口/build_all.py --check   # 只体检
python 统计局代码/人口/dashboard.py          # 驾驶舱
```

## 数据驾驶舱

`dashboard.py` → `年度数据/人口/人口数据驾驶舱.png`（16×9.6 in @200dpi）。

版式与另外两个分类同源，自上而下六层：

| 区块 | 内容 |
|---|---|
| 标题区 | 图标 + 「人口 · 数据驾驶舱」+ 数据区间，右侧年份与口径胶囊 |
| 年份滑轨 | 2016–2025 十个刻度，已走过段描深，当前年份落点 |
| KPI 条 | 年末总人口 / 城镇化率 / 出生率 / 自然增长率 / 65 岁及以上占比 |
| 速读条 | 一段「2025 速读」，数字全部由表实时算出，不写死 |
| 主副图 | 左：城乡人口堆叠面积 + 城镇化率圆点（双轴）；右：出生率 / 死亡率 / 自然增长率圆点 |
| 底部三联 | 年龄结构（100% 堆叠）、抚养比（三格迷你）、城乡人口比重（100% 堆叠） |

驾驶舱只吃 `01`、`02`、`03` 三张年度表——这三张是十年级别、指标连续的全口径序列；
`06`–`15` 是抽样调查表（每年样本量不同、2020 年缺），趋势可以看、**水平不能直接当全国数**，
放进攻坚看板会把口径不同的系列并排比较，因此只出逐表图。

## 文件命名规则

官网导出名一律是 `年度数据 (n).csv`，`n` 只反映下载顺序。本目录按**官方表序 + 内容**重命名，
`01-` 这类序号前缀只在文件系统里有意义，**图标题会自动剥掉它**（`render._ORDER_PREFIX`）。

## 已知的数据坑（代码里已处理）

- **2020 年整列缺失**。抽样调查表都没有 2020 年（那一年做的是七普，没有抽样调查），
  横向刻度会自然跳过，副标题写明「缺 2020 年」，**不插值、不连断档**。
- **07 与 08 不是重复件**。`分年龄组男性人口数` 与 `分年龄组女性人口数` 指标名与数值都不同，
  分别出图；真正的重复件是 `16-受教育程度_重复件.csv`（与 14 逐字节相同），已跳过。
- **单位藏在第二个括号里**。「性别比 (女=100) (人口抽样调查)」末尾那个括号是口径不是单位，
  按「最后一个括号」解析会把 21 格的单位全写成「人口抽样调查」。`stj_core.split_name_unit`
  现在会跳过不像单位的括号（`_UNIT_WORDS` + 含 `%`/`‰`/`=`/`/` 的才算单位）。
- **单位混用的单年表不能共用一根横轴**。七普那张表把「汉族人口 128631 万人」「性别比 105」
  「文盲率 2.7%」「家庭户规模 2.62 人/户」并列，画在同一根轴上是拿不同量纲比大小。
  单年点图已改为**按单位分面**：每组一根独立横轴、各自标注，组名压在面板上沿。
- **不能加总的量不标「占比」**。预期寿命 80.88 岁 ÷ 三项之和 = 34.5% 是没有意义的数字；
  七普那张表里汉族、男性、城镇人口互相重叠，之和也不等于任何口径的总人口。
  现在只有在**原表里存在同单位的合计行、且其数值与这组指标之和吻合**时才标占比
  （`charts._stated_total`），否则只写数值。
- **「15 岁及以上」这类口径不能当前缀剥掉**。剥公共前后缀时若把「15岁及以上」削掉，
  六格标题就只剩「人口数」「男性人口数」，读者会当成全年龄人口；代码对
  「岁 / 以上 / 以下 / 不满」这类词设了例外，宁可标题长一点也不丢口径。
- **抽样调查的绝对量级不是全国数**。`06`–`15` 的人数是样本量（约 1‰ 人口），
  看趋势可以，不能当全国人口数引用；驾驶舱因此只用全口径的 `01`–`03`。
- **性别比、总人口这类「贴顶」序列**：值都在 100–115（性别比）或 14 亿上下（总人口）附近，
  零基线面积图会显得很平——这是真实形状，不是画错；变化幅度由每格右上角的首末变化率给出。

## 口径提示（图内已标注）

`render.DATA_CAVEATS` 会在脚注里补口径。人口分类目前靠原表尾注自动带出：
「1981 年及以前人口数据为户籍统计数；1982、1990、2000、2010、2020 年为当年人口普查
推算数；其余年份为年度人口抽样调查推算数」。总人口含现役军人，城乡按常住人口划分。

## 与其他分类的关系

- 本目录的「年末总人口」「城镇人口」是**全国口径**；`年度数据/综合/` 里的民族自治地方
  数据是地区口径，不能互相校验。
- 出生率、死亡率、自然增长率为**千分率（‰）**，与「国民经济核算」里的百分比不是一套刻度，
  跨分类拼图时不要共用一根轴。
