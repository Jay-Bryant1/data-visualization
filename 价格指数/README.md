# 统计局代码 · 价格指数

生成 `年度数据/价格指数/` 下全部图表的脚本。共 **78 个源文件 → 78 张逐表图 + 1 张驾驶舱**。

> 取数一律走官网手工导出（年度数据 → 价格指数 → 选表 → 右上角「下载」），本项目**不含任何爬虫**。
> 站点由 WAF 保护，脚本直连会返回 302/403，手工导出是唯一可行的取数方式。

## 目录

```
统计局代码/
├── stj_core.py                 母版：解析 + 指标计算
├── charts.py                   母版：图版
├── render.py                   母版：批量流程
├── sync_core.py                母版分发：--check / --push / --pull
└── 价格指数/                    ← 本目录（自包含，可整目录拷走）
    ├── stj_core.py             核心副本（勿手改，由 sync_core.py 覆盖）
    ├── charts.py               核心副本
    ├── render.py               核心副本
    ├── build_all.py            分类入口
    ├── dashboard.py            数据驾驶舱（一页式看板）
    └── README.md

年度数据/价格指数/                ← 78 个 CSV + 78 张逐表图 + 1 张驾驶舱
```

三个核心模块在本目录各存一份，`sys.path` 只指向本目录，把本目录与
`年度数据/价格指数/` 一起拷走即可独立运行。改代码改母版，再用
`python 统计局代码/sync_core.py --push` 分发。

运行：

```bash
python 统计局代码/价格指数/build_all.py          # 出图
python 统计局代码/价格指数/build_all.py --check   # 只体检
python 统计局代码/价格指数/dashboard.py          # 驾驶舱
```

## 图版选择

| 数据形状 | 用的图版 | 涉及文件 |
|---|---|---|
| 指标 > 30 行 | 指标 × 年份矩阵热力图（单栏 46 行内，超出折两栏） | 69、70、71、74、75 |
| 5 年以上、行数适中 | 小倍数面积矩阵，指数走「100 基准偏离带」 | 01–68、72、73、76、77 |
| 4 年及以下 | 真时间轴散点矩阵（纵轴围绕 100，画 100 虚线） | 78 |

所有环比指数（单位「上年=100」）一律用 **100 基准**：带子落在 100 以上为涨价、
以下为跌价并换成沙色，比在 95–110 的轴上找零刻度直观。定基指数（02 号，1978=100）
不走这条规则——它从 100 一路涨到几百，零基线面积图才看得出指数式增长。

## 数据坑

- **全是环比指数，减 100 才是涨跌幅**。`100.0` 表示与上年持平，`97.4` 表示下降 2.6%。
  驾驶舱和逐表图的「涨跌」一律按 `值 − 100` 写成百分数，报告里直接引用不会错。
- **分类口径改过三次，跨段不可拼接**：
  - 2006–2015：八大类为食品、烟酒及用品、衣着、家庭设备用品及维修服务、
    医疗保健和个人用品、交通和通信、娱乐教育文化用品及服务、居住；
  - 2016–2020：食品烟酒、衣着、居住、生活用品及服务、交通和通信、
    教育文化和娱乐、医疗保健、其他用品和服务；
  - 2021–2025：末项改称「其他用品及**服务**」，其余同 2016 段。

  同一大类在不同段的子项数量也不同（如衣着 2006 段 5 项、2016 段 6 项、2021 段 3 项），
  逐表图的「仅 N 个年度有数据」提示即由此而来。
- **2006–2015 段缺 6 张表**（下载时未取）：全国版缺「交通和通信」「娱乐教育文化用品及服务」
  「居住」，城市版缺「食品」「烟酒及用品」「衣着」。农村版八张齐全，可作对照补齐。
- **两个口径已停发**：商品零售价格分类指数止于 **2022 年**（2023 年起不再发布）；
  固定资产投资价格指数止于 **2019 年**。图上右端留空，**不是漏采**，也未做插补。
- **工业生产者出厂价格指数分成三段**：`74` 是 2002–2011、`75` 是 2016–2025，**中间 2012–2015
  没有**；两段的行业分类也不同（2011 版国民经济行业分类 vs 2017 版），跨段比行业涨幅会犯口径错。
  `76` 是按「生产资料 / 生活资料」两大部分的另一种切法，与 `75` 的分行业不可加总对照。
- **农村商品零售 60 项里有 21 项只统计到较早年份**（如「石油及制品类」只有 2016 年），
  热力图右半大片白色是未发布，不是零值。
- **八大类之间不可加总**：国家统计局不公布 CPI 分类权重，八个大类的指数不能相加或平均。
  驾驶舱的排名只比方向与幅度。
- **2025 年数据为初步数**：居民消费价格 100.0（零涨幅）、农村 99.8（2016 年以来首次低于 100）、
  工业生产者出厂 97.4（连续三年低于 100），如有修订以官网为准。
