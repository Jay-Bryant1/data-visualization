# 统计局代码 · 对外经济贸易

生成 `年度数据/对外经济贸易/` 下全部图表的脚本。共 **101 个源文件 → 101 张逐表图 + 1 张驾驶舱**。

> 取数一律走官网手工导出（年度数据 → 对外经济贸易 → 选表 → 右上角「下载」），本项目**不含任何爬虫**。

## 目录

```
统计局代码/
├── stj_core.py                 母版：解析 + 指标计算
├── charts.py                   母版：图版
├── render.py                   母版：批量流程
├── sync_core.py                母版分发：--check / --push / --pull
└── 对外经济贸易/                ← 本目录（自包含，可整目录拷走）
    ├── stj_core.py             核心副本（勿手改，由 sync_core.py 覆盖）
    ├── charts.py               核心副本
    ├── render.py               核心副本
    ├── build_all.py            分类入口
    ├── dashboard.py            数据驾驶舱（一页式看板）
    └── README.md

年度数据/对外经济贸易/          ← 101 个 CSV + 101 张逐表图 + 1 张驾驶舱
```

三个核心模块在本目录各存一份，`sys.path` 只指向本目录，把本目录与
`年度数据/对外经济贸易/` 一起拷走即可独立运行。改代码改母版，再用
`python 统计局代码/sync_core.py --push` 分发。

运行：

```bash
python 统计局代码/对外经济贸易/build_all.py          # 出图
python 统计局代码/对外经济贸易/build_all.py --check   # 只体检
python 统计局代码/对外经济贸易/dashboard.py          # 驾驶舱
```

## 文件命名规则

官网导出名一律是 `年度数据 (n).csv`，`n` 只反映下载顺序。本目录按**官方表序 + 内容**重命名，
因为文件过百，序号补到三位（`001`–`101` 中的 `01`–`101`），保证在资源管理器里按表序排列。
图标题会自动剥掉序号前缀（`render._ORDER_PREFIX`）。

## 已知的数据坑（代码里已处理）

- **国别表动辄五十行以上，不能铺小倍数**。`06`/`07`/`13`/`20` 这类表有 49–62 个经济体，
  铺开要十几行小图；改为**矩阵热力图**后，行按最新一年量级排序、颜色是本行相对首个有数
  年份的倍数——同一张图里既看得出谁体量大，也看得出谁在涨。跨行不可比已在副标题注明。
- **矩阵热力图分两种着色**。率类（增速、指数）颜色即数值，暖＋冷−；量级类颜色是
  「相对本行首个有数年份的倍数」，避免把排序用颜色再画一遍。
- **`41`–`47` 是 2002–2014 的旧序列**，指标名为「实际利用外商其他投资」，与 2016 年起的
  外商直接投资序列不是同一口径，时间上也不重叠；只逐表出图，不与 `33`–`40` 拼接。
- **2025 年国别明细尚未发布**。`06`–`26`、`56`–`99` 的末列基本是空的，图右侧的空白是
  「未发布」而不是漏采；副标题按成因分开措辞。驾驶舱里伙伴排名自动回退到 2024 年。
- **2024 年大洋洲的合计行没有发布**（`11` 表里「中国同大洋洲及太平洋群岛进出口总额」2024、2025
  两列皆空，但澳大利亚、新西兰等分项有数）。若照常按已发布五洲归一，这一年会被悄悄重标成
  100%，与其余年份不可比；用分项求和补又比合计行少 0.04%（若干小岛国为空白），属于插补。
  因此驾驶舱的区域结构图只画到六洲齐全的 2023 年，并在副标题与脚注里写明原因。
- **`76` 只有 2020 一个年份**、`84` 只有 2022–2024。单点不画趋势线，只在真实年份落点，
  图上注明「仅 1 个年度有数据」。
- **汇率名字里的括号是量纲不是口径**。「人民币对美元汇率（美元=100）（元）」末尾两个括号，
  过去剥公共后缀会切进括号内，标题变成「美元汇率（美」；现已先把 `(美元=100)` 这类量纲括号
  整段剥掉，再压缩成「美元汇率」。
- **「中国香港 / 中国台湾 / 中国澳门」按规范书写**，不简写成地区名。
- **`中国同中华人民共和国进出口总额` 是原表自带的一行**（内地与港澳转口口径），
  与「亚洲合计」不是同一层级，排序时会落在伙伴中间，读图时以「合计」行对照。
- **单位混排的数量表**（`27`/`29`：万吨、吨、个、艘、辆）按行内倍数着色，副标题写明
  「各指标单位不同，颜色＝行内倍数、跨行不可比」，不给出跨商品的绝对值比较。
