# 统计局代码 · 就业人员和工资

生成 `年度数据/就业人员和工资/` 下全部图表的脚本。共 **29 个源文件 → 29 张逐表图 + 1 张驾驶舱**。

> 取数一律走官网手工导出（年度数据 → 就业人员和工资 → 选表 → 右上角「下载」），本项目**不含任何爬虫**。

## 目录

```
统计局代码/
├── stj_core.py                 母版：解析 + 指标计算
├── charts.py                   母版：图版
├── render.py                   母版：批量流程
├── sync_core.py                母版分发：--check / --push / --pull
└── 就业人员和工资/             ← 本目录（自包含，可整目录拷走）
    ├── stj_core.py             核心副本（勿手改，由 sync_core.py 覆盖）
    ├── charts.py               核心副本
    ├── render.py               核心副本
    ├── build_all.py            分类入口
    ├── dashboard.py            数据驾驶舱（一页式看板）
    └── README.md

年度数据/就业人员和工资/        ← 29 个 CSV + 29 张逐表图 + 1 张驾驶舱
```

三个核心模块在本目录各存一份，`sys.path` 只指向本目录，把本目录与
`年度数据/就业人员和工资/` 一起拷走即可独立运行。改代码改母版，再用
`python 统计局代码/sync_core.py --push` 分发。

运行：

```bash
python 统计局代码/就业人员和工资/build_all.py          # 出图
python 统计局代码/就业人员和工资/build_all.py --check   # 只体检
python 统计局代码/就业人员和工资/dashboard.py          # 驾驶舱
```

## 文件命名规则

官网导出名一律是 `年度数据 (n).csv`，`n` 只反映下载顺序。本目录按**官方表序 + 内容**重命名，
`01-` 这类序号前缀只在文件系统里有意义，**图标题会自动剥掉它**（`render._ORDER_PREFIX`）。

## 已知的数据坑（代码里已处理）

- **分行业明细只有最近两年**。`07`/`10`/`11`/`22`/`25`/`26` 六张表都有 9–10 个年份列，
  但行业明细只有 2023、2024 两年有数——2023 年起登记注册统计类别按
  《关于市场主体统计分类的划分规定》（国统字〔2023〕14 号）重新发布，此前只公布总量。
  铺成面积矩阵时每格只剩一根竖线，已改为**哑铃点图**，副标题与脚注写明口径调整，
  避免被读成「2016–2022 年漏采」。
- **哑铃图剔除「合计」行**。合计等于各行业之和，留在图里会把横轴拉到它的量级，
  19 个行业全挤在左端一厘米内；剔除后横轴按行业量级展开，排序与增减才有信息量。
- **同名不同义**：`16-个体户数与就业人数` 里的「城镇就业人数」是个体口径（2019 年 11,692 万），
  与全国「城镇就业人员」（47,535 万）差着一个量级；图中已改标「城镇个体就业人数」。
- **语序拗口**：原表「私营企业城镇就业人员」「个体城镇就业人员」剥掉公共后缀后剩
  「私营企业城镇」「个体城镇」，已做等价调序为「城镇私营企业」「城镇个体」。
- **合计行的名字被剥光**：`04` 表首行「城镇就业人员」剥掉「就业人员」只剩「城镇」，
  会被当成「城镇/乡村」里的一个分项；首行剥成范围词时统一标「合计」。
- **2023 年口径断点**：`04` 表尾注说明「从 2023 年起城镇非私营单位包括内资、港澳台投资和
  外商投资单位」。跨 2022/2023 年的增减在总量层面可比，但**分登记注册类型的结构不可直接连**。
- **亿元与「上年=100」混装**。`17`/`18` 一张表里既有亿元/元，又有指数；指数格走
  100 基准偏离带（上青下橙），标题不再重复标「（上年=100）」，改由副标题统一说明。
- **`19` 不是 `18` 的重复件**。`19` 覆盖 2016–2022，分类更细（股份合作/联营/有限责任/股份有限
  单列），且「其他单位」只含长尾（2022 年 78,376 元），与 `18` 的「其他单位」（109,895 元）
  不是同一口径，两张都保留、各自出图。
- **登记失业率 2022 年起停发**。最后有值的是 2020 年（4.0%），右侧空白不是漏采，
  脚注已带出原表说明。
- **私营企业投资者人数只统计到 2013 年**。`15` 表 15/70 个空格来自这里，
  副标题按「指标只统计到较早年份」措辞，不再误写成「2019 年未发布」。
- **2025 年私营/外商投资单位工资未发布**。`28`/`26` 止于 2024，驾驶舱 KPI 的对照值
  标注了年份，避免拿 2025 年的非私营工资去比 2024 年的私营工资。

## 口径提示（图内已标注）

- 就业人员为**年末数**，按常住地划分城乡，与人口分类的「年末总人口」是同一口径的分母；
  就业人员 ÷ 总人口 才是就业率，本分类不直接给比率。
- 城镇单位就业人员**不含私营单位**（2012 年起行业采用新分类，与前期不可比）；
  私营与个体单独成表。
- 平均工资是**城镇非私营/私营/外商投资单位就业人员的年平均工资**，不含个体与自由职业者，
  与「居民人均可支配收入」不是一套口径，不能互相校验。
- 城镇登记失业人数是**登记口径**，与调查失业率不同；后者本分类未收录。

## 与其他分类的关系

- `02`/`03` 的就业人员与「人口」分类的年末总人口同源，可做「就业人员/总人口」的派生指标。
- 工资总额（`17`/`20`）与「国民经济核算」的劳动者报酬口径不同：前者是单位工资总额，
  后者含个体经营收入与实物报酬，跨分类比较前先对齐口径。
- 分行业就业与「国民经济核算」的分行业增加值可以配对算劳动生产率，但行业分类版本
  需对齐（2012 年前后不可比）。
